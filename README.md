E-Commerce Shipping Analysis & Machine Learning

📌 Project Overview

This project focuses on analyzing an e-commerce shipping dataset and applying machine learning techniques to predict whether shipments will arrive on time. It includes data preprocessing, exploratory data analysis, model training, performance evaluation, and clustering.

🎯 Objectives

Analyze e-commerce shipping data to identify important patterns.

Perform data preprocessing and feature scaling.

Build and evaluate supervised machine learning models.

Apply K-Means clustering to explore customer or shipment patterns.

Compare model performance using appropriate evaluation metrics.

📊 Dataset

The project uses the E-Commerce Shipping Dataset, which contains shipment-related information.

Target Variable: Reached.on.Time_Y.N

Prediction Task: Predicting whether a shipment reaches on time.
